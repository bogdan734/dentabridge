## Contracts produced (everyone consumes these)
- Every model and port in PLAN.md "Shared contracts", exported from `dentabridge_core`
- `dentabridge_core.testing`: FakeVisionBackend, FakeFareEstimator, FakeTranslator
- `dentabridge_core.policy`: `lint`, `evaluate` (urgency), `review_status`, `render_patient_text`, `guard_note`, `texts`; CLI `dentabridge-lint`
- i18n/{en,ru}.json: the only source of patient-facing and legally significant strings (banner, disclaimers, AI disclosure, estimate footer, chips, consent text)
- `scripts/check`: the single gate for every workstream

## Contracts consumed
- None at M0. Afterwards: contract change requests filed in the other WS files

## Contract change protocol (lead only)
1. Read the request in the requesting WS file.
2. Edit core and bump CONTRACT_VERSION (minor for additive changes, major for breaking ones).
3. Regenerate packages/core/schemas/*.json and commit `F-cr<n>: <change>`.
4. Merge to main and tell the affected workstreams to rebase. WS02 re-runs `make contracts`.

## Gate
- `scripts/check` (quiet on success)
- `uv run pytest packages/core -q`
- `uv run dentabridge-lint --profile patient --locale en packages/core/src/dentabridge_core/i18n/en.json` (same for ru)

## Definition of done
- M0:
  - `scripts/check` green on a clean clone (`uv sync` → check);
  - CI green;
  - schema snapshots committed; every package imports;
  - `make help` lists the targets of every mk/*.mk stub.
- F2-F4:
  - the linter corpora pass and fail as labelled;
  - all 486 status combinations map to exactly one urgency rule;
  - every rendering passes the patient profile in EN and RU;
  - review_status stays "illustrative_not_clinically_reviewed" without a matching review record.
- Merge duty: merge ws branches in milestone order and re-run `uv lock` after each merge.
