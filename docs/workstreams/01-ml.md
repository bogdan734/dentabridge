- `uv run pytest packages/ml -q -m "not slow and not gpu and not network"`
- Manual, logged in docs/results/ml: `make data`, `make splits`, `make baselines`, `make eval-val`, and `make eval-test` once per release

## Compute rules
- Kaggle: one T4 per run (P100 unused); checkpoint every 500 steps to Kaggle output or a private HF repo.
- Colab: the fallback. The Mac: Ollama imports and small checks; a second job of the owner's may hold its GPU and RAM, so check before heavy work.
- Every run writes run.json: config digest, commit, hardware, rows, steps, throughput.

## Definition of done
- Splits:
  - roundtrip.md states the serving verdict and the logprobs result;
  - the data card resolves every UNVERIFIED data item with a date;
  - leakage tests green.
- Evaluation:
  - val.json has the zero-shot 4b/8b and D-FINE rows;
  - the lean Kaggle recipe is re-run from a clean session within the recorded CI;
  - release_gate.toml was committed before the first test-access log line;
  - test.json/test.md give, per finding, sens/spec with cluster-bootstrap CIs, ECE, risk-coverage, AKU-vs-AlphaDent shift, JSON-valid rate and a gallery.
- Release:
  - the card renders from results and passes the docs lint;
  - weights are pushed to a PRIVATE HF repo;
  - nothing from private/ appears in any committed file.
